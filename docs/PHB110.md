# 一加 11 CPH2449 / PHB110 钱包适配

状态：**本地候选包，尚未在手机上安装或验证登录、录卡。** 基线是上游 WalletFix4OOS 2.3.0。输入为 `PHB110_16.0.5.701(CN01)` 全量 ROM 中提取的组件；目标系统是 CPH2449、OxygenOS 16、KernelSU + Zygisk Next + Hybrid Mount。

## 实现

- 保留上游 Zygisk 库，只对 `com.finshell.wallet` 与 `com.unionpay.tsmservice` 的进程设置 `Build.MODEL=PHB110`。模块安装时创建 `/data/adb/walletfix/spoof_vars`；已有不同内容时安装中止。
- 用一加 11 国行 ROM 的 `com.heytap.vip`、`com.oplus.account`、`com.heytap.openid`、`com.heytap.tas`、`com.oplus.pay` 替换上游包中一加 12 的对应 APK 和 native 库。删除 donor ROM 的 VDEX/ODEX/ART 文件。
- 通过 KernelSU `system.prop` 设置 ROM 原值 `ro.product.cuptsm=ONEPLUS|ESE|01|02`，通过单独的 product 权限 XML 授予国行账号组件在 ROM 中拥有的 privapp 权限。原来的 `KeKeUserCenter` 目录由模块覆盖，停用模块并重启后应恢复海外版本。
- 钱包 `com.finshell.wallet` 5.44.9 与银联 TSM `com.unionpay.tsmservice` 01.01.13 作为独立 APK 输出，按上游方式单独安装。APK 内已包含与 ROM 外置目录一致的 arm64 so。

公开仓库**不包含**国行 ROM APK；本地构建脚本校验已核对的 APK SHA-256。`dist/` 被 Git 忽略。构建脚本不会连接或修改手机。

## 本机构建

从本仓库根目录执行 PowerShell。下面的 `rom-extracted` 是这次只读解包后已有的目录。需要上游官方 release ZIP 的 SHA-256 为 `E36C262046DA7CABA4DD656EA7E413BE36E3ABEE9F87956E26A92F85B0DEC706`。

```powershell
& 'C:\Users\husk1\AppData\Roaming\uv\python\cpython-3.12.16-windows-x86_64-none\python.exe' scripts\build_phb110.py `
  --base-zip 'D:\Projects\movewallet\tools\Wallet-Fix-for-OxygenOS-2.3.0-1064-8d00352-release.zip' `
  --rom-root 'D:\Projects\movewallet\rom-extracted' `
  --output-dir 'D:\Projects\movewallet\WalletFix4OOS\dist'
```

输出：`dist/WalletFix4OOS-PHB110.zip`、`dist/FinShellWallet.apk`、`dist/UPTsmService.apk`。

## 回滚

禁用模块后重启可撤销账号目录覆盖与 `system.prop`；钱包及 TSM 作为用户 App 仍保留，便于排查数据。

```powershell
& $adb -s 2d842a6c shell su -c '/data/adb/ksud module disable walletfix4oos'
& $adb -s 2d842a6c reboot
```

确认系统正常后，可卸载模块；模块的 `uninstall.sh` 只在配置文件由本模块创建且仍为 `MODEL=PHB110` 时删除该文件。卸载用户 App 会删除其本地数据，尤其是钱包卡片数据，应另行决定。

```powershell
& $adb -s 2d842a6c shell su -c '/data/adb/ksud module uninstall walletfix4oos'
& $adb -s 2d842a6c reboot
```
